# ROAD 95 dashboard design lock

This visual system is the approved baseline. Future updates must extend it rather than redesign it.

- Near-black and charcoal surfaces with fluorescent lime `#caff3a` as the only primary accent.
- Thin technical borders, restrained glow, rounded panels and compact uppercase labels.
- Premium dark athletic-performance/JARVIS atmosphere with realistic, shadow-rich imagery.
- The Today screen prioritizes the active session, compact status chips, media carousel, weekly status and the fixed Weight System panel.
- Training is the wider primary panel; the media carousel is the smaller secondary panel.
- Preserve typography scale, spacing rhythm, navigation structure, button language and responsive behavior unless the user explicitly requests a redesign.
- Never remove confirmed training or athlete data solely to simplify the interface; move detail into an appropriate secondary screen.
